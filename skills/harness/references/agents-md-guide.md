# AGENTS.md Guide

`AGENTS.md` is the always-loaded repo contract. Keep it short and stable.

## Include

- What the repository is for
- Canonical paths and ownership boundaries
- Required build, test, or validation commands
- Pointers to deeper docs and skills
- Safety rules that apply across the whole repo

## Leave Out

- Long codebase summaries
- One-off task instructions
- Generated directory listings
- Style rules already enforced by tooling
- Temporary recovery heuristics

When in doubt, link out instead of expanding this file.
